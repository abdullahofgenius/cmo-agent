# CMO Agent — Product brief

## Initial customer
Early-stage SaaS founders who can build products but do not have a full growth team.

## Core promise
Turn a website and connected first-party data into a focused weekly growth plan, prepared by specialist agents and controlled by human approvals.

## Operating principles
1. **Evidence before generation** — recommendations must point back to site, search or analytics signals.
2. **One coordinated plan** — specialist agents do not create disconnected task spam.
3. **Approval before action** — no external publishing, code changes or spend without explicit authorization.
4. **Measurable outcomes** — every action has an intended metric and evaluation window.
5. **Scoped access** — integrations receive the minimum required permissions.

## V1 agent team
- **Strategy:** chooses the sprint goal and prioritizes work.
- **SEO:** finds demand, technical gaps and content opportunities.
- **GEO:** improves machine-readable entity facts and answer-engine visibility.
- **Writer:** creates briefs and drafts using the approved brand profile.
- **Social:** repurposes approved insights into channel-native drafts.
- **Technical:** turns validated fixes into code proposals and, later, GitHub PRs.

## First user journey
1. Founder creates a workspace and enters a company URL.
2. CMO Agent audits the public site and explains the highest-impact gaps.
3. Strategy agent assembles a short action queue.
4. Founder approves, rejects or edits actions.
5. Connected agents prepare assets or implementation proposals.
6. Founder reviews the output before it is published or merged.
7. CMO Agent measures the agreed metric and reports what changed.

## Non-goals for the first release
- Fully autonomous publishing
- Unsanctioned community posting
- Black-box SEO scoring presented as fact
- Replacing strategic founder judgment
- Supporting every marketing channel at launch
